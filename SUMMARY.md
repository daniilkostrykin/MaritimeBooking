# Улучшение валидации данных в MaritimeBooking

## Общий обзор внесенных изменений

В ходе работы была значительно улучшена система валидации данных в приложении MaritimeBooking. Это включало создание специализированного класса валидации, замену всплывающих окон на более удобный вывод ошибок в столбик, а также добавление визуальной подсветки полей с ошибками.

## Класс Validator

Был разработан класс `Validator`, который содержит следующие методы валидации:

```java
public class Validator {
    // Проверка на пустоту
    public static boolean isNotEmpty(String value)

    // Проверка на числовое значение
    public static boolean isNumeric(String value)

    // Проверка на целое число
    public static boolean isInteger(String value)

    // Проверка формата email
    public static boolean isValidEmail(String email)

    // Проверка корректности даты
    public static boolean isValidDate(String date)

    // Проверка, что дата не в будущем
    public static boolean isNotFutureDate(String date)

    // Проверка, что строка содержит только буквы
    public static boolean isAlphabetic(String value)

    // Вспомогательный метод для валидации полей и добавления ошибок
    public static void validateField(String fieldName, boolean isValid, String errorMessage, List<String> errors)
}
```

## Улучшения в JDBCManager

- Добавлен метод `checkCustomerExists` для проверки существования клиента по email
- Скорректирована работа с целочисленным весом багажа
- Добавлена обработка ошибок при работе с датами
- Реализован безопасный механизм каскадного удаления рейса и всех связанных с ним данных

## Преимущества внесенных изменений

1. **Улучшение пользовательского опыта:**

   - Пользователь видит все ошибки сразу в одном месте
   - Визуальное выделение проблемных полей
   - Более понятные и информативные сообщения об ошибках

2. **Повышение безопасности данных:**

   - Строгая проверка типов данных
   - Валидация формата для важных полей (email, паспорт, даты)
   - Проверка существования связанных записей

3. **Улучшение сопровождаемости кода:**

   - Централизация логики валидации в отдельном классе
   - Стандартизация подхода к валидации на всех вкладках
   - Единый стиль обработки и отображения ошибок

4. **Предотвращение некорректного ввода данных:**
   - Проверка типов данных перед их обработкой
   - Предотвращение ввода будущих дат
   - Контроль формата ввода для паспортных данных и email
